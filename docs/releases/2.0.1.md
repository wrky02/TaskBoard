# 任务看板系统 2.0.1

2.0.0 基线先发布于 [GitHub Releases](https://github.com/wrky02/TaskBoard/releases/tag/v2.0.0)，本版随后修复使用反馈。

- 窗口图标：页面显式提供与 EXE / 安装器相同的多尺寸 ICO，登录前即可加载，修复 Edge 应用窗口无 favicon 而显示默认地球图标的问题。
- 标签管理：新增和重命名可用 Enter 确认；取消按钮和 Escape 仍取消。中文输入法组合期间的 Enter 不提交弹窗。
- 截止日期：采用用户选择的轻量月历方案，中文月份、周一开头、今天 / 明天 / 一周后、清除日期、今天边框与选中高亮。支持方向键、Home / End、PageUp / PageDown（加 Shift 切换年份）、Enter 确认和 Escape 取消。
- 日期保留本地年月日，不使用 UTC 转换；日期变更仍在任务草稿中，保存任务后才写入数据库。

## 验证

Linux：15 项接口/启动测试、数据回归、浏览器回归通过。新增覆盖图标未登录加载、标签 Enter/中文组合事件/取消、月末到闰年二月、跨月键盘操作、快捷日期、日期清除与取消草稿、窄窗口布局。

Windows 构建额外检查实际 Edge 应用窗口的大小图标；冻结程序检查 ICO 与日期脚本均正确打包。最终 Windows 结果见构建记录。

## 后续可选设计

当前保持 A 轻量月历。后续可独立选择：B 快捷输入（“明天”“下周一”等）；C 日程负载（每天显示任务数量）。另一项建议是统一侧栏 T· 标记与安装器看板图案，可选择延续看板图案或另行设计紫色 T 品牌图标。

真实用户桌面上已固定的旧快捷方式可能仍受 Windows 图标缓存影响；本版不删除用户的固定项或浏览器配置。真实中文输入法候选窗口仍需实机确认。
