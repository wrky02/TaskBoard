# 任务看板系统 2.0.0

本次发布保存 2.0 的已验证基线；后续图标、标签回车及日期选择器改进另行交付。

## 下载与安装

下载本页 Assets 中的 **Setup_TaskBoard_2.0.0.exe**，适用于 Windows x64。首次启动设置本机密码。安装器未做代码签名，发布者会显示为未知；可使用 SHA256SUMS.txt 校验下载文件。

## 新架构与功能

- 移除 Qt / WebEngine，改用 Python 本地服务、SQLite 和系统 Edge 应用窗口；未找到 Edge 时使用默认浏览器。
- 重新设计登录页、导航、看板与任务抽屉；支持三阶段拖动、搜索筛选、标签、批量操作、归档与回收站。
- 保留手动检查清单、里程碑、附件与图片预览、附件版本备注、日历与到期提醒；任务模板正式退休。
- 抽屉修改先暂存，保存时统一提交；支持 CSV / XLSX 导出、完整备份与恢复。
- 数据保存在本机；关闭窗口后服务继续运行，侧栏“退出程序”可完全退出。

## 从旧版升级

先退出旧版并备份完整数据库与附件；建议在数据副本上验收。新版不自动查找其他安装目录的数据，可在“数据与设置”恢复旧版完整备份。旧结构迁移前自动备份，历史检查项保留。卸载保留 Data。请勿让旧版直接操作升级后的唯一数据库。

## 验证与已知问题

安装包原样来自 [已通过的 Windows 构建](https://github.com/wrky02/TaskBoard/actions/runs/39015780834)，代码提交 e2cb5e1；发布标签包含其后的验证文档更新，不含产品代码变化。

已通过 15 项接口/启动测试、数据层回归、浏览器流程、冻结 EXE 冒烟、真实隔离安装与卸载数据哈希检查。

已知问题：窗口及任务栏图标显示不正确；标签新增暂需点击“确定”；截止日期使用基础原生日期框。这些问题在下一版处理。真实 Windows 中文输入法、多显示器、旧安装升级仍需实机验收。登录密码不加密数据库及附件。
