# 3.0.1 · 原生界面重做

重新设计 3.0 的原生 WPF 界面，恢复 2.1 的深色侧栏、紫色强调色、分栏看板和清晰的信息层级。程序仍为独立 Windows 桌面应用，不使用浏览器或 WebView。

- 侧栏采用矢量 T 标识、导航图标与明确的选中状态，设置和锁定固定在底部。
- 看板增加任务统计；矮窗口自动收起统计区，给任务列表保留空间。
- 随包提供 Noto Sans SC 常规与粗体字形，统一标题、正文和控件字体，无需另装字体。
- 搜索和快速添加都有提示文字，筛选器、文本框、按钮、滚动条和折叠面板统一样式。
- 卡片使用文字标题、淡色标签、优先级和简短正文，日期、检查清单进度与附件数量集中在底部。
- 加入今日、完成、复制、归档、删除移入卡片的“⋯”菜单，也可右键打开。批量勾选在“批量选择”模式下显示。
- 分栏有独立底色、数量和添加入口；空列与无搜索结果有提示。
- 编辑窗口重新安排标题、状态、优先级和日期；详情分组可折叠。日历选中日期使用紫色，保留今天、明天、一周后和清除日期快捷操作。
- 撤销入口只在操作可撤销的 15 秒内显示。

数据结构、旧版迁移、备份和安装标识沿用 3.0。安装前关闭正在运行的旧版本；升级后继续使用原 Data 目录。
