# 3.0.0 原生 Windows 桌面版

这次重构将外部 Edge 应用窗口替换为原生 WPF 控件。启动、登录、编辑任务、附件预览和设置页面均不调用浏览器。没有 WebView2、QtWebEngine、Electron，也不启动本地 HTTP 服务。

## 架构和安装

- WPF / .NET 自包含 Windows x64 程序，安装器内包含运行组件，用户无需另装 .NET 或 Python。
- Python 数据引擎作为私有子进程运行，通过重定向的标准输入/输出传递 JSON，SQLite 与附件仍在本机保存。复用经过回归验证的数据规则，不是把网页换壳。
- 同一个安装标识与 Data 目录，兼容 1.3/2.x 数据和 ZIP 备份；升级保留数据，首次旧结构迁移前保留安全备份。升级前关闭旧版程序。跨版本实例锁阻止两个版本同时写入。
- 发布者元数据 wrky02；未取得受信任证书前仍为未签名包，详见 [正式签名配置](../CODE-SIGNING.md)。

## 功能

原生看板、拖动改变状态、优先级、今日计划、标题/正文/状态/标签/日期筛选、排序、保存视图、原生日历；快捷输入回车创建、标签回车确认和中文日期快捷选择。

任务编辑保留说明、手动检查清单、进度、全选完成提示、里程碑、标签、重复任务、依赖、提醒、操作记录和附件版本。附件支持文件选择、拖入、读取进度、名称搜索、图片左右切换和另存为。草稿与正式保存分开，包含新增附件，关闭编辑器保留草稿，重启后可以恢复。

批量编辑状态/优先级/日期/标签；归档、回收站、恢复与永久删除；移动/删除/归档后 15 秒撤销。重复任务支持日/周/月，以及固定日期/完成日期两种生成基准。

原生托盘支持重新打开和退出；关闭方式可在设置中记住。程序已解锁并在托盘运行时可发出系统气泡提醒，支持稍后提醒；完全退出、锁定或系统休眠期间不发送提醒，恢复运行后补查。Windows 通知设置或专注模式可能隐藏气泡，应用内仍列出未处理提醒。

每日首次启动自动完整备份，保留 7 份；ZIP/旧 Data 目录导入前预览任务与附件数量，恢复前安全备份；CSV/Excel 导出；诊断默认排除用户内容与凭据。

## 当前验证

- Linux：WPF 交叉编译；27 项应用/存储/私有管道测试。
- Windows：由 Native Windows installer 工作流构建并安装后，使用 UI Automation 检查实际原生控件、快速添加、标签回车、草稿恢复、托盘、重新打开、退出及卸载保留数据，同时监控进程树和 TCP 监听。
- 真实中文输入法候选窗、不同 DPI/多显示器、实际企业防病毒策略需用户机器复核，自动输入文本不能代替输入法实机验收。
