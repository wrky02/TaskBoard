# 任务看板系统 2.1.0 · 综合升级

本版落实两组功能建议及紫色 T 品牌统一，安装器发布者与公司信息为 **wrky02**，主页 https://github.com/wrky02 。不使用 Qt 或内嵌 WebEngine；Windows 使用独立 Edge 应用窗口与原生系统托盘。

## 工作安排

- 紧急／高／普通／低优先级，卡片标记、筛选及优先级／截止日期排序。手动排序模式可拖动。
- 我的今天汇总未完成的今日到期、逾期和主动加入今日计划的任务，加入今日计划不修改截止日期。
- 顶部输入标题、回车快速创建。保存常用视图包含搜索、标签、优先级、阶段、日期及排序；同名视图会更新。
- 批量修改截止日期、优先级、阶段及标签，显示部分失败原因。批量日期可输入“清除”，有重复或提醒规则时需先关闭规则。
- 手动检查清单显示完成进度；全部勾选后可选择在保存时完成任务。任务标题、状态、日期固定在抽屉顶部；清单、里程碑、附件及记录可折叠。
- 截止日期显示今天截止、还剩 N 天或逾期 N 天；保留 2.0.1 的中文月历。

## 重复、依赖与提醒

- 每天／每周／每月重复，按原截止日期或完成日期计算。任务从未完成变为完成时生成下一项，同一项重新打开再完成不会重复生成。
- 按原截止日期重复时跳过已错过周期，生成首个晚于今天的日期。每月规则保留原日号，例如 1 月 31 日 → 2 月末 → 3 月 31 日；按完成日期则以实际完成日为基准。
- 下一项继承标题、备注、标签、优先级、依赖和提醒设置；检查项、里程碑重置，附件不复制。手动复制任务关闭重复规则，避免无意产生额外重复系列。
- 依赖禁止自身和循环；未完成或在回收站的依赖阻止保存、拖动或批量标记完成。归档的已完成依赖仍有效。彻底删除被依赖任务前需先移除依赖。
- 每项任务可设置提前一天或当天、本机时间提醒；支持 15 分钟后再提醒或“知道了”。约每 30 秒刷新。确认状态与稍后时间持久化。
- 提醒属于应用内提示，需要工作区打开且已登录。关闭窗口、留在托盘或完全退出时不会弹出任务提醒；重新打开后补显示尚未确认的提醒。

## 编辑与附件

- 文件拖入任务抽屉、按名称搜索、图片左右切换、文件大小及任务／附件上传进度。
- 编辑期间约每 1.5 秒保存独立草稿，包含新增附件。重新打开工作区可选择恢复；恢复后仍需“保存任务”才写入正式任务。只以“草稿已保存”提示作为落盘依据，强制结束前尚未保存的输入不保证恢复。
- 最多保留 20 份草稿；与正式数据一样受登录保护，并包含在完整备份中。其他页面已修改原任务时，恢复的旧草稿不能直接覆盖。
- 删除到回收站、归档、拖动后 15 秒内可撤销。后续修改会阻止冲突撤销；生成下一次重复任务后，只有下一项尚未修改、且未被其他任务依赖时才能撤销完成。
- 标签支持颜色、使用数量、合并及输入时已有标签提示；合并会将原标签引用移到目标标签。

## 数据与 Windows

- 2.1 结构升级前保存 `before-v2.1-*.zip`；每天首次启动完整自动备份，`Data/backups` 保留最近 7 份。备份失败在设置页显示，不删除已有有效备份。
- ZIP 备份先校验并显示日期、任务与附件数量，再确认替换。也可选择旧版 Data 目录（最多 100 MB）；检测到 WAL 时要求关闭旧版并导出 ZIP，避免导入不完整数据库。完整 ZIP 上限仍为 2 GB。
- 设置页显示版本、数据路径、备份状态。一键诊断报告只含系统／版本／计数／完整性结果，排除任务标题、正文、附件、用户名、本地路径、密码、启动凭据和草稿。
- 窗口、任务栏、快捷方式、安装器和侧栏统一紫色 T。Windows 启动时要求安装 Edge；浏览器工作区采用独立临时配置，退出后清理，不修改日常浏览器配置。
- Windows 关闭窗口后可选择退出、留在系统托盘或重新打开，并可记住退出／托盘选择。托盘支持打开工作区和退出；设置页可修改关闭偏好。未保存修改仍有浏览器关闭提示。
- 发布者元数据为 wrky02；安装器未签名，Windows 安全提示中的“已验证发布者”需要另行配置签名证书。

## 验证

Linux 已通过 23 项接口／数据／启动回归、继承数据层回归和完整浏览器流程。浏览器覆盖优先级／今日计划／常用视图、重复／依赖／提醒、批量／撤销／标签、附件拖入／搜索／图片切换、带附件草稿恢复、诊断及关闭偏好。

Windows 构建还将执行原生大小图标、关闭到托盘／重新打开／关闭退出、冻结 EXE、真实安装、发布者注册信息及卸载数据保留验证；最终构建结果以交付记录为准。
