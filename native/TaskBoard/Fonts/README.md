# Noto Sans SC

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1; see OFL.txt.

The bundled TrueType font is a static weight-400 instance of NotoSansSC[wght].ttf, generated with fontTools 4.61.1:

```python
font = TTFont("NotoSansSC-variable.ttf")
font = instantiateVariableFont(font, {"wght": 400}, inplace=True, optimize=True, updateFontNames=True)
font.save("NotoSansSC-Regular.ttf")
```
